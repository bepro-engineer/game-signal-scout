ゲームの情報と画像（Steam）

  • ゲームの名前・短い説明・ジャンル・遊び方（一人・協力・対戦・コントローラ）・対応する機種・日本語への対応・発売日と、ゲームの画像は、Steam のストアの作品情報を使っています。
  • ゲームの画像は、このサイトのサーバーに保存・複製していません。皆さんのブラウザが Steam の画像の配信サーバーから直接読み込んで表示しています。
  • 遊ばれている規模（同時に遊ばれている人数の順位）は Steam Web API の集計です。このサイトが観測した人数ではありません。

プレイヤーの声

  • プレイヤーの声は、取得元（Steam の公開のレビュー・Bluesky の公開の投稿など）ごとに集めています。人数はこのサイトが数えたもので、取得元ごとに数え、取得元をまたいで足しません。
  • Linux・Steam Deck での動作の報告は、ProtonDB の公開配布データ（ODbL 1.0）を加工したものです。
  • 投稿者の名前や ID は、このサイトに載せていません。

フォント

文字の表示に Google Fonts の M PLUS Rounded 1c と Noto Sans JP（SIL Open Font License）を使っています。

権利の帰属

  • 作品の名前・画像・あらすじなどの著作権その他の権利は、それぞれの権利者に帰属します。
  • 引用している投稿の権利は、それぞれの投稿者に帰属します。
  • ゲームの情報は Steam のストアの作品情報です。
  • このサイトが作った集計・判定・図・文章（AI による解説文を含む）は、このサイトのものです。扱いは利用規約・データ利用ポリシーのとおりです。

Sources and rights

Game information and images (Steam)

  • Game names, short descriptions, genres, play modes (single-player, co-op, versus, controller), platforms, Japanese support, release dates and game images come from the Steam store pages.
  • Game images are not stored or copied on this site's server. Your browser loads them directly from Steam's image servers.
  • Player scale (rank by concurrent players) is Steam Web API data, not the people this site observed.

Player voices

  • Player voices are collected per source (public Steam reviews, public Bluesky posts and others). The counts are made by this site, per source, and never added across sources.
  • Linux and Steam Deck play reports come from the ProtonDB public data (ODbL 1.0), as processed by this site.
  • Names and IDs of the people who wrote them are not shown on this site.

Fonts

Text uses M PLUS Rounded 1c and Noto Sans JP from Google Fonts (SIL Open Font License).
