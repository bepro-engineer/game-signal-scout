このサイトについて

仕事などで自由な時間が限られる人が、週末や連休に遊ぶゲームを選ぶとき、自分に合うか・買う前に注意することはないかを、根拠と一緒に確かめられるようにする試作です。

載せていること

  • 作品の情報（画像・短い説明・ジャンル・遊び方・日本語への対応・遊べる機種・発売日）は Steam のストアの作品情報から、遊ばれている規模（順位・同時に遊んだ人数の最大）は Steam Web API から取っています。規模は目安で、面白さや自分に合うかの評価ではありません。
  • 載せる作品は、プレイヤーの報告・声の多い作品と、Steam で多く遊ばれている作品です（いまは最大 120 作品）。
  • プレイヤーの声は、公開の SNS の投稿のうち、そのゲームについて書かれたものです。宣伝・配信の告知などは除いています。結び付けには誤りを含みます。

買う前の注意の見つけ方

  • 14 日の間に、別々の機材構成から 5 件以上の報告があり、「遊べない」という報告の割合が、その前の 60 日より 30 ポイント以上変わったものを「遊べなくなった」「直った」として出します（規則の版 {{ v.version }}）。
  • 「書かれていたこと」は、根拠になった報告の文中の言葉で数えています（例: NVIDIA・起動直後に落ちる・更新の後から）。2 件以上の報告に出たものだけを、件数と一緒に出します。言葉の一致なので誤りを含み、原因とは限りません。
  • 報告の原文は訳さず、そのまま載せています（項目名だけ日本語にしています）。

情報源と更新

  • Steam のストアの作品情報（30 日ごとに取り直し）と、Steam Web API の「最も遊ばれているゲーム」（毎日）。画像は Steam の配信元から直接表示しています。
  • 動作の報告: ProtonDB の公開配布データ（ODbL 1.0 / DbCL 1.0）。配布は月に 1 回程度です。
  • プレイヤーの声: Bluesky の公開の投稿。投稿者は特定できない形に置き換え、削除された投稿は消します。
  • 毎朝 6:15 に取り込みと作り直しをします。

分からないこと

  • クリアまでの時間、プレイヤーの満足度・評価、向いている人・向いていない人は、根拠になるデータがまだないため出していません。
  • 買う前の注意は Linux・Steam Deck の報告によるもので、Windows で同じことが起きているかは分かりません。
  • 報告が少ないゲームでは、数件で割合が大きく動きます。
  • Valve・ProtonDB・各ゲームの開発元とは関係ありません。
