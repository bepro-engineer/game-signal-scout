# ページの設計（2026-11-09）

すべてのページを、次の 1 人の利用者から設計する。部品はこの表から決め、ここにない部品は置かない。

**利用者**: 仕事で自由に使える時間が少ない日本の大人。週末や連休に、自分に合って満足できる PC・家庭用のゲームを遊びたい。
買って合わなかったり、時間を無駄にしたりはしたくない。英語は得意ではない。

**サイトの価値**: 世界のプレイヤーが実際に遊んで書いた「何をして → 何が起きて → 何が面白かったか（醍醐味）」から、
次に遊ぶゲームを見つけ、買う前に「自分に合うか・日本語で遊べるか・つまずく所はないか」を判断できる。

**全ページ共通の決まり**
- どのページも、利用者の問いを 1 つに絞って答える。数・出典・作り方の説明は、開いたときだけ見せる。
- 日本語の印を出すページには、必ず凡例を付ける（印より前に置く）。
- 判断に使えない表示は置かない。例: 開発元の国、投稿の言語圏、話題の人数の増減。
- 根拠のない推薦・満足度・プレイ時間は作らない。体験がまだ読めていないときは、そう書く。

## 1. トップ（`index.html`）
| 項目 | 内容 |
|---|---|
| 来る人・きっかけ | 週末の前、何を遊ぶか決めていない人。ブックマークや検索から来る |
| 知りたいこと | 「いま、遊んで面白いゲームは何？」 |
| 置くもの（上から） | ① いちばん具体的な醍醐味を、ゲームの場面の大きな絵の上に 1 文で ② その根拠（何をして → 何が起きたか）と書いた人数 ③ 「どんな面白さを味わいたい？」：実際に体験のある面白さの種類だけを、絵の札で ④ 醍醐味のカード（作品名・根拠・日本語の印）⑤ すべて見るへの道 |
| 留まる理由（醍醐味） | 絵と 1 文で「これ、やってみたい」と感じる。種類の札を押すと、同じ面白さのゲームが続けて見つかる |
| 持ち帰る価値 | 候補のゲームが 1〜3 本決まる |
| 置かないもの | 言語圏の地図、話題の人数の増減、集計の用語 |

## 2. 見つけた面白さ（`finds.html`）
| 項目 | 内容 |
|---|---|
| 来る人・きっかけ | トップの種類の札や「すべて見る」から。何が面白いかで選びたい人 |
| 知りたいこと | 「この種類の面白さを味わえるゲームはどれ？ 本当に面白いの？」 |
| 置くもの | ① 面白さの種類の札（件数つき）と「日本語で遊べる作品だけ」② 凡例 ③ 醍醐味のカード（人数・反対の声・注意）④ 買う前に知っておきたいこと（不満・注意）⑤ 出どころ（畳む） |
| 留まる理由 | 種類を替えるたびに、別の面白さのゲームが並ぶ。反対の声や注意も一緒に見えるので、信用して読める |
| 持ち帰る価値 | 自分の好きな面白さに合う候補と、その弱点 |

## 3. 誰と・どう遊ぶか（`solo` `coop` `versus` `pad` の 4 ページ）
| 項目 | 内容 |
|---|---|
| 来る人・きっかけ | 遊び方が先に決まっている人。例: 友達と週末に協力したい、ソファでコントローラーで遊びたい |
| 知りたいこと | 「その遊び方で、何が面白いゲームは？」 |
| 置くもの | ① その遊び方の醍醐味（協力なら役割分担と連携が決まる瞬間、など）を見出しに ② その遊び方で実際に遊んだ人の醍醐味のカード ③ 対応している作品の一覧（ストアの表記。補助） |
| 留まる理由 | 「友達とこうやって遊んだら盛り上がった」という具体的な場面が読める |
| 持ち帰る価値 | 一緒に遊ぶ人に勧められる候補 |
| 未解決 | その遊び方の体験は、まだ少ない。少ないときは、少ないと書く |

## 4. 作品詳細（`work.html`）
| 項目 | 内容 |
|---|---|
| 来る人・きっかけ | カードを押した人。買うかどうかを決めたい人 |
| 知りたいこと | 「自分に合う？ 日本語で遊べる？ つまずく所は？」 |
| 置くもの（上から） | ① 絵・作品名・ジャンル・機種 ② 日本語の対応（凡例つき。メニュー・字幕・声を分けて）③ プレイヤーが見つけた面白さ（醍醐味と根拠）④ 買う前に知っておきたいこと（不満・注意）⑤ 作品の説明 ⑥ 公式・ストアへの道 |
| 留まる理由 | 面白さと弱点の両方が具体的に読め、迷いが減る |
| 持ち帰る価値 | 買う・買わないの判断 |
| 置かないもの | 話題の人数のグラフを主役にしない（下に畳む）。開発元の国は参考として最後に |

## 5. 作品を探す（`search.html`）
| 項目 | 内容 |
|---|---|
| 来る人・きっかけ | 作品名が分かっている人、条件で絞りたい人 |
| 知りたいこと | 「あのゲームはどう？」「日本語で遊べるアクションは？」 |
| 置くもの | ① 名前の検索 ② 絞り込み（ジャンル・遊び方・日本語・機種）③ 凡例 ④ 結果のカード（絵・名前・日本語の印・醍醐味があれば 1 文） |
| 留まる理由 | 結果のカードに醍醐味が出るので、名前しか知らなかったゲームの面白さが分かる |
| 持ち帰る価値 | 探していた作品の詳細への近道 |

## 6. このサイトについて（`about`）
| 項目 | 内容 |
|---|---|

| 価値 | 情報の確からしさを自分で判断できる |

## いまのデータで出せること・出せないこと
- 出せる: 醍醐味と根拠（上位の作品から読み始めたところ）、日本語の対応（販売元の表記）、ジャンル・遊び方・機種（ストアの表記）、場面の絵。
- まだ少ない: 遊び方ごとの体験、反対の声。
- 出せない（作らない）: 満足度の点数、クリアまでの時間、根拠のない「向いている人」。
